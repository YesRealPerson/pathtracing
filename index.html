CUDA Accelerated Path Tracing with ReSTIR GI

PUT THE RAYS IN THE TRIANGLE
Stephen Park, Connor Lu, Abe Karikkineth, Charlie Si

Summary

Accelerate path tracing using a GPU and implement modern path resampling algorithms such as ReSTIR. Further exploration involves modern resampling such as ReSTIR GI and AI denoising (Intel OIDN).

Problem Description

Path tracing is a highly hardware intensive task. The homework Path Tracer implementation utilizes the CPU, where rendering large and complex scenes at higher resolutions would lead to long runtimes in the realm of hours. Accelerating the time for rendering graphics is an important problem in the industry from rendering complex animations to real time rendering for video games. To address this we want to improve the performance of the class path tracer implementation from high levels of parallelism. While we explore thread level parallelism in the base implementation of our path tracer, we leave open the idea of exploring further thread and data parallelism using the GPU. Further we seek to implement path resampling algorithms such as ReSTIR and ReSTIR GI. Past this we would like to explore modern developments such as ReSTIR PT. In addition, given enough time, we would like to explore AI based denoisers such as Intel Open Image Denoise (OIDN).

Goals and Deliverables

Our baseline goal is that we can implement some form of realtime raytracing, while possibly not up to a visually strong standard, an operational standard. Thus we anticipate that a successful project hinges upon successfully implementing a fully CUDA accelerated path tracer. We can demonstrate speedup by a significant increase in ray calculations per second, alongside total render time. While we anticipate that we can achieve further speed and quality increases within the four weeks by implementing modern algorithms, we do not fully understand how taxing implementing each of these algorithms are. Therefore, they are left as mostly stretch goals. Ultimately, we hope to have a realtime ray traced scene renderer for realtime scene navigation.

Plan to Deliver

  • Accelerate Path Tracer with CUDA
    • Significant path tracing speedup
  • Implement ReSTIR
    • Less noise at lower sample rates for direct lighting.
    • Stores a light sample per pixel into a reservoir, drawing from neighboring and previous frame reservoirs at render.

Hope to Deliver

  • Implement ReSTIR GI
    • Implements reservoirs for indirect light as well.
  • OIDN
    • An AI image denoising model that we can use so we don't have to use as many rays per pixel.

Stretch

  • ReSTIR PT
    • Full path reuse for better quality on glossy and specular surfaces
